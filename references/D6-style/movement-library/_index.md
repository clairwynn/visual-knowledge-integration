## How to use

- For the movement perspective of an ideation task, go through modes/schools/ (hard routing); this library does not take part in hard routing;
- For style re-creation / disambiguation / mixing tasks: start with the method blocks in art-movements (seven-layer deconstruction / failure-point opposition / mixing arbitration), then look up the corresponding card here;
- Color anchors can be taken directly as the palette starting point for D3/palette-strategy;
- Each card's failure points are the custom check items for re-creation verification (never use a universal checklist).

## Data-quality statement

- The six-dimension breakdown of the hand-drawn style group (274 cards) is a corpus-derived version with brief entries — that group's main criteria are the one-line description and the color anchors;
- Movement cards carry between four and six layers of information; look up by card-name subheading.
