# D1 · 空间分配（Spatial Allocation）

> 本文件管：主体占比带宽、留白（负空间）分档与情绪语义、质感化留白规范、正负空间的质量闸。
> 怎么用：画幅定完后第二件事——决定主体与空白各占多少、空成什么质地。

## 定义

空间分配＝画幅面积在"主体（正空间，positive space）"与"空（负空间，negative space / 留白）"之间的划分，以及划分所携带的情绪。

## 机制

负空间不是"没画的部分"，而是** actively 设计的空**：它决定主体的孤立程度、画面的呼吸密度，并且是观者情绪的第一来源（空旷→孤独，拥挤→紧张）。留白同时承担三个职能：聚焦（隔离主体）、呼吸（密度调节）、预埋（给文字/视线/下一张图留位）。

## 判据

### 主体占比带宽（经验值，按题材）

| 题材 | 主体占比 | 说明 |
|---|---|---|
| 面部特写/填充式 | 70–90%+ | 边界出画，核心特征完整 |
| 头肩像 | 面部占画幅 60–70% 高度 | 电商头像/身份照经验区间 |
| 半身人像 | 45–65% | |
| 全身人像 | 35–55% | 竖幅中人物+脚下缓冲 |
| 环境人像 | 20–40% | 人成为环境中的点 |
| 产品主图 | 40–60% | 居中+底部阴影着陆 |
| 极简/负空间构图 | ≤35% | 配合大面积质感留白 |
| 风景主体（孤树/孤舟） | 10–30% | 尺度对比即情绪 |

### 留白三档（主体-空间比情绪表，共识值）

| 档位 | 语义 | 典型用法 |
|---|---|---|
| 50/50 | 对峙、紧张、均衡 | 双主体对抗、镜像构图、海报正负形 |
| 30/70 | 舒适呼吸（70% 留白版） | 人像偏置、产品海报、封面字位预留 |
| 10/90 | 孤独、崇高、渺小 | 极简海报、旷野孤树、日之丸 |

> 三档与五档的关系：三档是**情绪配方**（按主体:空间比选语义），五档是**细调谱系**（按留白占比微调密度）。同一占比可承载不同读数——50% 留白在五档中属甜点区（舒适），在 50/50 配方中却读作对峙张力：占比相同、布局不同（居中均衡 vs 偏置对峙）、语义不同。使用顺序：先按情绪定三档配方，再用五档微调密度。

### 留白五档谱系（细调用，经验值）

| 留白占比 | 情绪读数 |
|---|---|
| 10–20% | 窒息拥挤，压迫叙事 |
| 30–40% | 紧凑、热闹、信息密集 |
| 40–50% | 甜点区：多数单主体画面的默认起点 |
| 60–75% | 疏朗、安静、庄重 |
| 80–90% | 孤立、崇高、近乎抽象 |

可用总区间约 30–70%（甜点区 40–50% 为经验值，非定论，按情绪目标上下移动）。

### 质感化留白规范（硬规则）

1. **禁止"空洞的空"**：留白区必须能描述出质地或氛围——雾、纸纹、暮色渐变、水面反光、颗粒、暗部微光。"纯色背景"式留白是廉价感的来源；空必须"是什么"，不能只是"没有"。
2. **留白方向要设计**：主体朝向、视线、动势所指向的一侧留白更多（方向性留白），让空白成为"即将发生什么"的容器（与 D4/framing-room 的 lead room 同构）。
3. **留白不能锁死**：留白区里至少留一条可走的视觉路径（弱引导线/光带/渐变），否则画面成为"主体+真空"。

### 负空间双清单（用与避的条件判断——留白不是默认，是选项）

- **适用条件**（多数成立才选）：主体小/孤立/孤独；要传达尺度或辽阔；情绪是安静、极简、忧郁；背景简单干净；主体剪影强且易读。
- **回避条件**（任一命中即慎用）：留白区自身杂乱；主体缺清晰轮廓；想要能量与张力；背景与主体竞争注意力；多主体需要相互关联。

### 质量闸（两条否定式约束，用于自检）

- 留白区禁止塞入杂物（"无杂乱背景"）。
- 画面中每个元素必须可回答"它为什么在这里"（"只留必要之物"）。

## 边界

- 占比数字是设计起点不是靶心：情绪意图可以推翻带宽（压抑主题的特写可低于常规，崇高主题的孤树可以小到 10%）。
- 多主体画面没有单一"主体占比"，改用区域分配（见 multi-subject）。
- 留白档与画幅联动：竖幅天然多纵向留白，选档时按"画幅减去主体后的实际余量"计，不按想象计。

## 反例

- 反例 1：主体 30% 居中+四周均分空白——孤立感被居中抵消，画面呆滞。修法：偏置+方向性留白。
- 反例 2：海报留白区只写了"蓝色背景"——空无质感，画面廉价。修法：写清质地（雾面渐变/颗粒纸纹/水面微光）。
- 反例 3：为追求极简把留白拉到 85%，但主体边缘紧贴画框——空起来了主体却"撞墙"。留白与边距要同时设计（见 edges-cropping）。
