# D8 · Core Lexicon

> This file covers: authoritative definitions of the core concepts across the library (English term plus a one-line mechanism plus a pointer to the authority file).
> How to use: the first stop for concept localization — look up "what is X / which domain does it belong to" here; the concept-localization step of the learn function cites this table directly.

## How to use this file

- Each entry: **English term** → one-line definition → one-line mechanism → authority file.
- This table is a "concept map"; the depth lives in the authority files. When the two disagree, the authority file wins and this table is corrected.

## Composition structure (D1)

- **aspect ratio**: the frame's length-to-width ratio and orientation. The frame's first skeleton, before every decision. → D1/aspect-ratio
- **composition type**: the nameable relation between elements and frame geometry (thirds / symmetry / diagonal …). → D1/composition-types-1/2
- **power points**: the intersections of the thirds lines, where the eye naturally rests. → D1/composition-types-1
- **negative space**: deliberately designed "emptiness" carrying focus / breathing / pre-planting. → D1/spatial-allocation
- **visual path**: the designed route for the eye through the frame (entry–road–endpoint). → D1/visual-path
- **leading line**: a linear structure that sends the gaze toward the subject (real / implied / hidden). → D1/visual-path
- **balance**: the distribution of visual weight around a fulcrum (symmetrical / asymmetrical / radial / crystallographic). → D1/balance
- **depth layering**: the foreground–midground–background three-layer structure, the minimal complete configuration of depth illusion. → D1/depth-layering
- **frame within a frame**: a frame nested inside the frame, a composite device for focus + depth + relation. → D1/framing
- **tangent (merge)**: the accident band where contours "just touch". → D1/edges-cropping, D7/F17

## Light and tonality (D2)

- **four variables of light**: direction / quality / ratio / color temperature — the complete description of a beam. → D2/light-fundamentals
- **lighting ratio**: the brightness difference between key and shadow (2:1 friendly → 8:1 dramatic). → D2/light-fundamentals
- **hard/soft light**: the sharpness of the shadow boundary, decided by source size and distance. → D2/light-fundamentals
- **tonality**: the overall structure of value (high key / low key / mid-key). → D2/tonality
- **tonal separation**: the brightness difference between subject and background, the strongest separation device. → D2/tonality
- **shadow signature**: the single shadow shape on the face that is the evidence of a lighting type. → D2/portrait-lighting
- **motivated light**: a source whose origin can be pointed to inside the scene. → D2/direction-quality
- **volumetric light**: light made visible in a medium (beams / Tyndall effect). → D2/atmosphere

## Color (D3)

- **60-30-10**: the area-proportion framework of dominant / secondary / accent. → D3/proportions
- **color harmony**: the structural relation between hues (seven schemes). → D3/harmony
- **complementary**: the highest-tension relation of two hues opposite on the wheel. → D3/harmony
- **color weight**: the contribution of temperature / value / saturation to visual weight. → D3/weight-contrast
- **warm advance, cool recede**: the stable rule that warm colors read forward and cool colors recede. → D3/weight-contrast
- **figure-ground**: the subject (figure) and background (ground) that perception separates automatically. → D5/figure-ground
- **echo hue**: the ≤2% reappearance of the accent at the far end — the color closed loop. → D3/weight-contrast
- **palette**: the fixed, limited color set written down before starting (3–5 colors). → D3/palette-strategy

## Lens and viewpoint (D4)

- **shot size**: the six-grade ladder of framing range (EWS → ECU). → D4/shot-size
- **camera angle**: viewpoint height and tilt axis — the grammar of power. → D4/angle
- **Dutch angle**: a tilted horizon axis, the semantics of imbalance. → D4/angle
- **focal length**: the breadth of the angle of view, the grammar of spatial relations (wide exaggeration / long compression). → D4/focal-length
- **perspective**: the geometric projection rules from three dimensions to two (0 / 1 / 2 / 3 point). → D4/perspective
- **vanishing point**: the convergence point of parallel lines, a psychological direction in space. → D4/perspective
- **depth of field**: the band of distances in sharp focus, the scalpel of attention. → D4/dof
- **headroom**: the clearance between the subject's head and the frame (four grades). → D4/framing-room
- **lead room / look room**: the clearance ahead of a gaze or momentum, a psychological direction. → D4/framing-room

## Visual psychology (D5)

- **Gestalt**: the laws by which the whole precedes the sum of parts in perceptual grouping (six laws). → D5/gestalt
- **visual weight**: the perceptual mass by which an element attracts attention (six factors). → D5/visual-weight
- **attention priority**: the weight order of face > text > high contrast > saturated warm color > motion. → D5/attention
- **Von Restorff effect**: the single odd item among similars is remembered first. → D5/attention
- **eye movement models**: the F / Z / Gutenberg scanning lines. → D5/eye-movement
- **first fixation**: the default landing point of the gaze. → D5/eye-movement
- **squint test**: the self-check that reduces the frame to its value structure. → D5/tests

## Diagnosis (D7)

- **weak composition**: a frame state in which compositional decisions are missing or failed (seven causes). → D7/cause-tree
- **review protocol**: the six-step frame-reading procedure. → D7/protocol
- **adjustment/restructure**: the two levels of prescription. → D7/prescriptions
- **review gates**: the five serial acceptance gates. → D7/review-gates

## Style (D6)

- **AI-slop**: the "authorless" look of median composition plus over-smoothing. → D6/ai-defaults
- **median composition**: the statistical mid-value frame with position / shot size / viewpoint all defaulted. → D6/ai-defaults
- **authenticity**: the degree to which a frame reads as a real moment, coming from disciplined imperfection. → D6/authenticity
- **style DNA**: the three-layer feature set of composition habits / light-and-color recipe / texture and brushwork. → D6/art-movements
- **texture**: the information layer of surface physical properties and imaging traces. → D6/texture
