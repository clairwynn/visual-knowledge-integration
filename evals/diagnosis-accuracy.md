## 评分细则

1. **根因判定**：回答指认的根因与标定同支同级=1.0；同支不同根因=0.5；异支=0；多根因题命中主根因即算命中。
2. **处方级别**：实际开出的级别=标定级别 → 合规；标定微调却开重构 → 计"误开"一次（即使诊断根因对了）。
3. **证据要求**：诊断必须含画面位置指认（"右下角的 X"）；无证据的诊断该题计 0.5 上限。
4. **陷阱题说明**：D-06/D-19/D-20 允许"微调失败后升级"路径——一次会话内先微调不算误开；直接开重构且未论证"结构层根因"才算误开。
5. 通过线：平均分 ≥0.75 且误开率 ≤2/20（=10%，与 README 协议及评分细则一致）。
