## 选择决策树

```
画面任务是什么性质？
├─ 有明确用途/平台/转化目标（电商、封面、卡片、海报）
│   ├─ 需要可信可读 → 商业实战派
│   └─ 需要版面感/文字配合 → 平面构成派
├─ 有情绪/叙事目标
│   ├─ 讲一个瞬间/故事 → 电影导演派
│   ├─ 宁静/意境/呼吸 → 东方画理派
│   ├─ 孤独/崇高/极简 → 极简减法派
│   └─ 真实感/在场感 → 摄影纪实派
├─ 有"为什么这样排"的求知需求
│   ├─ 解释感知机制 → 格式塔心理派
│   └─ 解释空间结构 → 摄影光学派
├─ 有形式正统/经典美诉求 → 经典学院派
├─ 有"好看但说不出"的分析需求 → 风格美学派
├─ 有"AI 味/平庸感"的困扰 → 潮流数媒派
└─ 有"打破/刺激/难忘"的诉求 → 观念反叛派（野狗档知识后盾）
```

## 主备搭配惯例（经验值）

- 默认双派制：主派定结构，备派供校验。常用组合：
  - 学院派（主）+ 格式塔（校验感知）
  - 导演派（主）+ 光学派（校验物理）
  - 极简派（主）+ 东方画理（留白深化）
  - 商业派（主）+ 平面构成（版面）
  - 数媒派（主）+ 观念反叛（打破默认）
- 混派纪律：一次最多两派（多了没有立场）；两派冲突时主派说了算。

## 与体验档的联动

- 专家档：点名为主，VKI 建议需给理由。
- 经理档：VKI 自动推荐主+备并说明理由（本文件决策树是推荐引擎）。
- 甲方档：自动选派，用生活语言转述，不出现派名。
- 野狗档：强制观念反叛派+随机杂交一派。

各流派文件的统一结构：宣言 / 核心思维方式 / 技法库 / 量化判据 / 适用场景 / 与他派差异 / 反例与边界。
